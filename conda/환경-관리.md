# Conda 환경 관리

## 환경 생성 / 삭제

```bash
# 새 환경 생성 (Python 버전 지정)
conda create -n sharp python=3.13
conda create -n myenv python=3.11

# 환경 활성화 / 비활성화
conda activate sharp
conda deactivate

# 환경 목록 보기
conda env list

# 환경 삭제
conda env remove -n myenv

# 환경 복제 (백업용)
conda create -n sharp_backup --clone sharp
```

## 환경 전환 동작

### deactivate 없이 바로 activate 가능

`conda activate`는 현재 환경을 자동으로 빠져나오고 새 환경으로 전환한다. 명시적으로 `conda deactivate`를 먼저 할 필요 없다.

```bash
conda activate sam2
# sam2 환경 상태
conda activate videomama
# → 자동으로 sam2 → videomama로 전환됨
```

다만 내부적으로는 환경이 **스택처럼 쌓이는 구조**라서, `conda deactivate`를 하면 이전 환경(sam2)으로 돌아간다.

### 다른 환경이 활성화된 상태에서 conda create 가능

`conda create -n`은 현재 활성화된 환경과 무관하게 별도 디렉토리(`envs/` 아래)에 새 환경을 만든다. base든 sam2든 어디서 실행해도 결과가 동일하다.

```bash
conda activate sam2
conda create -n videomama python=3.9 -y   # ✅ 문제 없음
conda activate videomama                   # ✅ 바로 전환 가능
```

## 패키지 관리

```bash
# 패키지 설치
conda install numpy
conda install -c nvidia cuda-toolkit=12.6    # nvidia 채널에서 설치
conda install -c conda-forge gcc_linux-64=12  # conda-forge 채널에서 설치

# pip로 설치 (conda에 없는 패키지)
pip install -r requirements.txt
pip install gsplat==1.5.3

# 설치된 패키지 목록
conda list
pip list

# 특정 패키지 버전 확인
python -c "import torch; print(torch.__version__)"
python -c "import torch; print(torch.cuda.is_available())"
```

## 환경 내보내기 / 재현

```bash
# 현재 환경을 yml로 저장
conda env export > environment.yml

# yml로부터 환경 재생성
conda env create -f environment.yml

# pip 패키지만 저장
pip freeze > requirements.txt
```

## 다른 디스크에 환경 만들기

`/home` 디스크가 꽉 찼을 때, 여유 있는 디스크에 conda 환경을 설치하는 방법.

### 방법 1: --prefix로 특정 경로에 생성

```bash
# 이름(-n) 대신 경로(-p)로 지정
conda create -p /data/envs/sharp python=3.13

# 활성화도 경로로
conda activate /data/envs/sharp
```

단점: `conda env list`에 이름 대신 전체 경로가 표시되고, activate할 때도 매번 경로를 입력해야 함.

### 방법 2: .condarc에서 기본 경로 변경 (추천) ⭐

`~/.condarc` 파일에 환경 디렉토리를 지정하면, 앞으로 `-n 이름`만 써도 해당 경로에 생성됨.

```bash
# .condarc 편집 (파일 없으면 새로 만들어짐)
nano ~/.condarc
# 저장: Ctrl + O → Enter / 나가기: Ctrl + X
```

```yaml
# ~/.condarc
envs_dirs:
  - /data/conda/envs        # 여유 있는 디스크 (최우선)
  - ~/miniconda3/envs       # 기존 경로 (fallback)

pkgs_dirs:
  - /data/conda/pkgs        # 패키지 캐시도 옮기면 더 좋음
```

설정 후:
```bash
conda create -n sharp python=3.13    # → /data/conda/envs/sharp 에 생성됨
conda activate sharp                  # 이름만으로 활성화
conda env list                        # 정상적으로 이름 표시
```

### 기존 환경을 다른 디스크로 옮기기

conda 환경은 경로 의존성이 있어서 `mv`만 하면 깨짐. export → 재생성이 안전함.

```bash
# 1. 현재 환경 export
conda activate sharp
conda env export > sharp.yml

# 2. 새 위치에 재생성
conda deactivate
conda env remove -n sharp
conda env create -f sharp.yml -p /data/envs/sharp

# 또는 .condarc 설정 후 이름으로
conda env create -f sharp.yml -n sharp
# → /data/conda/envs/sharp 에 생성됨
```
