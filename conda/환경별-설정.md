# Conda 환경별 환경변수 설정

## 문제 상황

`~/.bashrc`에 환경변수를 넣으면 **모든 세션**에 적용된다.  
특정 conda 환경에서만 CUDA 경로나 `CUDA_VISIBLE_DEVICES`를 쓰고 싶을 때가 있다.

## 해결: activate.d / deactivate.d 스크립트

`conda activate` 시 자동 실행되는 스크립트를 만든다.

### 구조

```
~/miniconda3/envs/{환경이름}/etc/conda/
├── activate.d/
│   └── env_vars.sh      ← activate 시 실행
└── deactivate.d/
    └── env_vars.sh      ← deactivate 시 실행 (원복)
```

### 설정 방법 (예: sharp 환경)

```bash
# 1. 디렉토리 생성
mkdir -p ~/miniconda3/envs/sharp/etc/conda/activate.d
mkdir -p ~/miniconda3/envs/sharp/etc/conda/deactivate.d

# 2. activate 스크립트 작성
cat > ~/miniconda3/envs/sharp/etc/conda/activate.d/env_vars.sh << 'EOF'
#!/bin/bash
# 원래 값 백업
export OLD_PATH=$PATH
export OLD_LD_LIBRARY_PATH=$LD_LIBRARY_PATH

# CUDA 12.4 경로 우선
export PATH=/usr/local/cuda-12.4/bin:$PATH
export LD_LIBRARY_PATH=/usr/local/cuda-12.4/lib64:$LD_LIBRARY_PATH

# RTX 3090(sm_86)만 타겟 (TITAN Xp 제외)
export TORCH_CUDA_ARCH_LIST="8.6"

# GPU 0번(RTX 3090)만 사용
export CUDA_VISIBLE_DEVICES=0
EOF

# 3. deactivate 스크립트 작성 (원복)
cat > ~/miniconda3/envs/sharp/etc/conda/deactivate.d/env_vars.sh << 'EOF'
#!/bin/bash
export PATH=$OLD_PATH
export LD_LIBRARY_PATH=$OLD_LD_LIBRARY_PATH
unset TORCH_CUDA_ARCH_LIST
unset CUDA_VISIBLE_DEVICES
unset OLD_PATH
unset OLD_LD_LIBRARY_PATH
EOF
```

### 확인

```bash
conda activate sharp
echo $TORCH_CUDA_ARCH_LIST   # → 8.6
nvcc --version               # → 12.4
echo $CUDA_VISIBLE_DEVICES   # → 0

conda deactivate
echo $TORCH_CUDA_ARCH_LIST   # → (빈 값)
echo $CUDA_VISIBLE_DEVICES   # → (빈 값)
```

> 💡 **다른 환경에도 동일하게 적용 가능**: `~/miniconda3/envs/{환경이름}/etc/conda/activate.d/` 경로만 바꾸면 된다.
