# Git 기본 명령어

## 초기 설정 (최초 1회)

```bash
git config --global user.name "seungho"
git config --global user.email "your-email@example.com"
```

## 저장소 생성 & 연결

```bash
# 새 저장소 초기화
git init

# GitHub 원격 저장소 연결
git remote add origin https://github.com/username/repo-name.git

# 기존 저장소 클론
git clone https://github.com/apple/ml-sharp.git
```

## 일상적인 작업 흐름

```bash
# 1. 변경사항 확인
git status

# 2. 파일 추가 (스테이징)
git add .                   # 모든 변경 파일
git add README.md           # 특정 파일만

# 3. 커밋
git commit -m "SHARP 프로젝트 설치 기록 추가"

# 4. GitHub에 푸시
git push origin main
```

## 자주 쓰는 명령어

```bash
# 변경 이력 보기
git log --oneline

# 변경사항 비교
git diff

# 마지막 커밋 메시지 수정
git commit --amend -m "수정된 메시지"

# 원격에서 최신 코드 가져오기
git pull origin main

# submodule 가져오기
git submodule update --init --recursive
```

## .gitignore

프로젝트 루트에 `.gitignore` 파일을 만들어 추적하지 않을 파일을 지정:

```
# Python
__pycache__/
*.pyc
*.egg-info/

# 환경
.env
*.pt
*.pth

# OS
.DS_Store
Thumbs.db
```
