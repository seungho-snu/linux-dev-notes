# VS Code 단축키 / 팁

## Markdown 미리보기

```
Ctrl + Shift + V       마크다운 렌더링 미리보기 (새 탭)
Ctrl + K → V           편집 + 미리보기 좌우 분할 (K 누르고 손 떼고 V)
```

> 💡 GitHub에서 받은 README.md 등을 열면 기본은 텍스트 모드.
> 위 단축키로 표, 이미지, 코드블록 등이 적용된 상태로 볼 수 있음.

## 자주 쓰는 단축키

### 기본

```
Ctrl + Shift + P       명령 팔레트 (모든 기능 검색)
Ctrl + P               파일 빠른 열기 (파일명 검색)
Ctrl + ,               설정 열기
Ctrl + `               통합 터미널 열기/닫기
Ctrl + B               사이드바 토글
```

### 편집

```
Ctrl + D               현재 단어 선택, 반복하면 동일 단어 다중 선택
Ctrl + Shift + K       현재 줄 삭제
Alt + ↑/↓              줄 위/아래로 이동
Shift + Alt + ↑/↓      줄 복제
Ctrl + /               주석 토글
Ctrl + Shift + [/]     코드 접기/펼치기
```

### 검색

```
Ctrl + F               파일 내 검색
Ctrl + H               파일 내 찾기/바꾸기
Ctrl + Shift + F       전체 프로젝트에서 검색
Ctrl + Shift + H       전체 프로젝트에서 찾기/바꾸기
```

### 멀티 커서

```
Alt + 클릭             클릭한 위치에 커서 추가
Ctrl + Alt + ↑/↓       위/아래 줄에 커서 추가
Ctrl + D               같은 단어에 커서 추가 (반복 가능)
Ctrl + Shift + L       동일 단어 전체 선택
```

### 터미널

```
Ctrl + `               터미널 열기/닫기
Ctrl + Shift + `       새 터미널 생성
```

> ⚠️ VS Code 터미널에서 `Ctrl+U`, `Ctrl+K` (bash readline 단축키)는 VS Code가 가로챔.
> 입력 지우려면 `Ctrl+C`를 사용.
