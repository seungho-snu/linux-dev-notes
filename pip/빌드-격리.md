# pip 빌드 격리 (--no-build-isolation)

## 문제 상황

CUDA 관련 패키지를 설치할 때 torch가 이미 설치되어 있는데도 `ModuleNotFoundError: No module named 'torch'`가 발생하는 경우가 많다.

```
pip install flash-attn
→ Installing build dependencies... done
→ Getting requirements to build wheel ... error
→ ModuleNotFoundError: No module named 'torch'
```

## 원인: 빌드 격리 (Build Isolation)

pip은 기본적으로 패키지를 빌드할 때 **임시 가상환경**을 새로 만들어서 그 안에서 빌드한다. 이 임시 환경에는 현재 환경에 설치된 torch가 존재하지 않기 때문에 실패한다.

```
pip install flash-attn
  └→ 임시 빌드 환경 생성 (torch 없음)
    └→ import torch → ❌ 실패

pip install flash-attn --no-build-isolation
  └→ 현재 conda 환경 그대로 사용 (torch 있음)
    └→ import torch → ✅ 성공
```

## 해결: --no-build-isolation

임시 환경을 만들지 않고 **현재 환경을 그대로** 사용해서 빌드하도록 지정한다.

```bash
# torch를 먼저 설치한 뒤
pip install torch==2.6.0 torchvision==0.21.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124

# CUDA 패키지 빌드 시 격리 해제
pip install flash-attn --no-build-isolation
pip install -e . --no-build-isolation
```

## 자주 영향받는 패키지들

빌드 시점에 `import torch`를 하는 패키지들이 해당된다:

- `flash-attn`
- `xformers`
- `gsplat`
- `diff-gaussian-rasterization` (3D Gaussian Splatting)
- `simple-knn`
- `tinycudann`

> 💡 경험상 **torch 의존 CUDA 패키지를 빌드할 때는 거의 항상 `--no-build-isolation`을 붙인다**고 생각하면 된다.

## -e 옵션 (editable mode)

함께 자주 쓰이는 `-e` 옵션도 정리한다.

| 명령 | 동작 |
|------|------|
| `pip install .` | 패키지를 site-packages에 복사. 소스 수정해도 반영 안 됨 |
| `pip install -e .` | 소스 폴더를 직접 참조 (링크). 코드 수정 시 즉시 반영 |

`-e`는 `--editable`의 약자. 현재 디렉토리의 `setup.py` 또는 `pyproject.toml`을 읽어서 패키지를 등록한다. 연구용 코드에서 수정하면서 바로 테스트할 때 유용하다.

## extras_require: 선택적 의존성 그룹 (.[dev], .[train] 등)

`setup.py`나 `pyproject.toml`에 선택적 의존성 그룹을 정의할 수 있다.

```python
# setup.py 예시
setup(
    install_requires=["torch", "numpy"],          # 기본 의존성
    extras_require={
        "dev": ["pytest", "flake8", "black"],     # 개발/테스트용
        "train": ["wandb", "accelerate"],         # 학습용
    }
)
```

| 명령 | 설치 범위 |
|------|----------|
| `pip install -e .` | 기본 의존성만 |
| `pip install -e ".[dev]"` | 기본 + dev 그룹 |
| `pip install -e ".[train]"` | 기본 + train 그룹 |
| `pip install -e ".[dev,train]"` | 기본 + dev + train |

> 💡 따옴표(`""`)는 쉘에서 `[]`를 특수문자로 해석하는 걸 방지하기 위한 것이다.
