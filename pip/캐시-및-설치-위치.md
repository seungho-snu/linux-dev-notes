# pip 캐시 / 설치 위치 관리

`pip install` 중 디스크가 꽉 찰 때, 용량을 먹는 3군데와 위치 변경 방법.

> 📚 전체 캐시 일괄 이동은 → [bash/캐시-디스크-관리.md](../bash/캐시-디스크-관리.md)

## 용량 먹는 3군데

| 위치 | 내용 | 기본 경로 |
|------|------|----------|
| site-packages | 실제 설치되는 패키지 | conda 환경 폴더 안 |
| pip 캐시 | 다운로드된 `.whl` 파일 | `~/.cache/pip` |
| 빌드 임시 폴더 | 컴파일 중 임시 파일 (gsplat 등) | `/tmp` |

---

## 1. 패키지 설치 위치 (site-packages)

활성화된 conda 환경 안에 설치됨.

```bash
# 어디에 설치되는지 확인
pip show pip | grep Location
# → /data/conda/envs/sharp/lib/python3.13/site-packages

python -c "import site; print(site.getsitepackages())"
```

`.condarc`로 conda 환경을 다른 디스크로 옮겼으면 여기는 자동으로 해결됨.
(→ [conda/환경-관리.md](../conda/환경-관리.md) "다른 디스크에 환경 만들기" 참고)

## 2. pip 캐시 위치 확인 / 변경

### 현재 위치 확인

```bash
# 캐시 디렉토리 경로
pip cache dir
# → /home/seungho/.cache/pip

# 캐시 크기/개수 정보
pip cache info
```

### 위치 변경

```bash
# 방법 1: 환경변수 (~/.bashrc에 추가하면 영구 적용)
export PIP_CACHE_DIR=/data/cache/pip

# 방법 2: pip 설정 파일로 영구 변경
pip config set global.cache-dir /data/cache/pip

# 설정 확인
pip config list

# 변경 확인
pip cache dir
```

### 캐시 비우기 / 캐시 없이 설치

```bash
# 캐시 비우기 (즉시 용량 확보)
pip cache purge

# 캐시 없이 설치 (다운로드 파일 안 남김)
pip install -r requirements.txt --no-cache-dir
```

## 3. 빌드 임시 폴더 (TMPDIR)

C++/CUDA 컴파일이 필요한 패키지(gsplat, flash_attn 등)는 빌드 중 `/tmp`에 수 GB 사용.

```bash
# /tmp 용량 확인
df -h /tmp

# 빌드 임시 폴더 변경
mkdir -p /data/tmp
export TMPDIR=/data/tmp
pip install -r requirements.txt
```

---

## 디스크 꽉 찼을 때 빠른 해결

```bash
# 1. 캐시 비우기
pip cache purge

# 2. 캐시 없이 재설치
pip install -r requirements.txt --no-cache-dir

# 3. 그래도 안 되면 빌드 임시 폴더도 변경
export TMPDIR=/data/tmp
pip install -r requirements.txt --no-cache-dir
```

## 영구 설정 (~/.bashrc)

```bash
export PIP_CACHE_DIR=/data/cache/pip
export TMPDIR=/data/tmp
```
