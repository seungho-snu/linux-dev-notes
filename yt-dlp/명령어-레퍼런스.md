# yt-dlp 명령어 레퍼런스

유튜브 및 기타 동영상 사이트에서 영상을 다운로드하는 CLI 도구.

## 설치

### pip (Linux/WSL/Mac)

```bash
pip install yt-dlp

# 업데이트
pip install -U yt-dlp
# 또는
yt-dlp -U
```

### GitHub Releases에서 직접 다운로드

https://github.com/yt-dlp/yt-dlp/releases/tag/2026.03.17

| 플랫폼 | 파일 |
|--------|------|
| Windows 64bit | `yt-dlp.exe` (Python 불필요, 단독 실행) |
| Windows ARM64 | `yt-dlp_win_arm64.exe` |
| Linux | `yt-dlp` (Python 3 필요) |
| Linux (단독실행) | `yt-dlp_linux` (Python 불필요) |
| Linux ARM64 | `yt-dlp_linux_aarch64` |
| macOS | `yt-dlp_macos` |

> 💡 Windows에서 Python 없이 쓰려면 `yt-dlp.exe`를 받아서 PATH가 잡힌 폴더에 넣으면 됨.
> `yt-dlp.exe`가 있는 폴더에서 cmd 열고 바로 실행해도 OK.

### 기타

```bash
# Linux (apt)
sudo apt install yt-dlp

# Linux (snap)
sudo snap install yt-dlp

# Windows (winget)
winget install yt-dlp

# macOS (brew)
brew install yt-dlp
```

## 기본 다운로드

```bash
# 최고 화질 영상 + 최고 음질 오디오 합쳐서 다운로드 (가장 많이 씀) ⭐
yt-dlp -f bestvideo+bestaudio URL

# 기본 (알아서 적당한 화질로)
yt-dlp URL

# 최고 화질 단일 파일 (영상+오디오 합쳐진 것 중에서)
yt-dlp -f best URL
```

> ⚠️ `bestvideo+bestaudio`는 영상과 오디오를 따로 받아서 합치므로 **ffmpeg가 설치되어 있어야** 합니다.
> `best`는 합쳐진 파일 중 최고 화질이라 ffmpeg 없이도 되지만, 화질이 떨어질 수 있음.

## 포맷 확인 및 선택

### 사용 가능한 포맷 목록 보기

```bash
yt-dlp -F URL
```

### YouTube 포맷 ID (itag) 전체 표

영상마다 제공되는 포맷이 다름. 인기 영상일수록 AV1이 있고, 오래된 영상은 H.264만 있을 수 있음.

#### DASH 비디오 (영상만, 오디오 없음)

| 해상도 | AV1 HFR High | AV1 HFR | VP9 HDR HFR | VP9 HFR | VP9 | H.264 HFR | H.264 |
|--------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| | MP4 | MP4 | WebM | WebM | WebM | MP4 | MP4 |
| 4320p (8K) | — | 402 / 571 | — | 272 | — | — | — |
| 2160p (4K) | 701 | 401 | 337 | 315 | 313 | — | — |
| 1440p | 700 | 400 | 336 | 308 | 271 | — | — |
| 1080p | 699 | 399 | 335 | 303 | 248 | 299 | 137 |
| 720p | 698 | 398 | 334 | 302 | 247 | 298 | 136 |
| 480p | 697 | 397 | 333 | — | 244 | — | 135 |
| 360p | 696 | 396 | 332 | — | 243 | — | 134 |
| 240p | 695 | 395 | 331 | — | 242 | — | 133 |
| 144p | 694 | 394 | 330 | — | 278 | — | 160 |

- **HFR** = High Framerate (최대 60fps), 비-HFR은 30fps 이하
- **AV1 HFR High** = 일반 AV1 대비 비트레이트 3~4배 높은 고품질 버전 (매우 인기 영상에만 존재)
- **571 vs 402**: 둘 다 8K AV1이지만 571이 약 50% 높은 비트레이트. 둘 다 있는 영상도 있고 하나만 있는 경우도 있음
- AV1 포맷은 **인기 영상에만** 제공됨 (조회수 수백만 이상)
- 1440p 이상 H.264는 360° 영상에서만 제공
- AV1은 HDR이 될 수 있음 (별도 비-HDR AV1은 제공 안 함)

#### DASH 오디오 (오디오만)

| ID | 컨테이너 | 코덱 | 비트레이트 | 비고 |
|----|---------|-------|-----------|------|
| 140 | MP4 | AAC LC | 128 Kbps | 가장 흔함, 호환성 좋음 |
| 139 | MP4 | AAC HE v1 | 48 Kbps | 저품질 |
| 249 | WebM | Opus | ~50 Kbps | 저품질 |
| 250 | WebM | Opus | ~70 Kbps | 중간 |
| 251 | WebM | Opus | ≤160 Kbps | 최고 음질 ⭐ |
| 256 | MP4 | AAC HE v1 | 192 Kbps | 5.1 서라운드 (드묾) |
| 258 | MP4 | AAC LC | 384 Kbps | 5.1 서라운드 (드묾) |

### 특정 포맷 번호로 다운로드

```bash
# 영상 포맷 ID 하나만 (오디오 없이 영상만 받음)
yt-dlp -f 401 URL                      # 4K AV1 영상만

# 영상 + 오디오 조합 (+ 로 연결)
yt-dlp -f 401+251 URL                  # 4K AV1 영상 + Opus 최고 음질 오디오
yt-dlp -f 137+140 URL                  # 1080p H.264 + AAC 오디오
yt-dlp -f 313+251 URL                  # 4K VP9 + Opus 오디오

# 8K 다운로드
yt-dlp -f 571+251 URL                  # 8K AV1 (고비트레이트) + Opus 오디오
yt-dlp -f 402+251 URL                  # 8K AV1 (일반) + Opus 오디오
```

> ⚠️ **`+`는 영상+오디오 조합 전용**. `401+571`처럼 비디오+비디오를 합치는 게 아님!
> 401(4K)과 571(8K) 둘 다 비디오 전용 스트림이라, 합치면 에러나거나 의미 없음.

### 여러 포맷 중 가능한 것 선택 (fallback)

```bash
# 571이 있으면 571, 없으면 402, 그것도 없으면 401 (쉼표로 우선순위)
yt-dlp -f "571/402/401+251" URL

# 가장 좋은 AV1, 없으면 VP9, 없으면 아무거나
yt-dlp -f "bestvideo[vcodec^=av01]/bestvideo[vcodec^=vp9]/bestvideo+bestaudio" URL
```

### 코덱 / 해상도 지정

```bash
# 특정 코덱 선호
yt-dlp -f "bestvideo[vcodec^=av01]+bestaudio" URL       # AV1 영상
yt-dlp -f "bestvideo[vcodec^=avc1]+bestaudio" URL       # H.264 영상
yt-dlp -f "bestvideo[vcodec^=vp9]+bestaudio" URL        # VP9 영상

# 해상도 제한
yt-dlp -f "bestvideo[height<=1080]+bestaudio" URL       # 1080p 이하 최고
yt-dlp -f "bestvideo[height=2160]+bestaudio" URL        # 정확히 4K
yt-dlp -f "bestvideo[height<=720]+bestaudio" URL        # 720p 이하

# 코덱 + 해상도 조합
yt-dlp -f "bestvideo[vcodec^=av01][height<=2160]+bestaudio" URL  # 4K 이하 AV1
```

### 포맷 정렬 (-S 옵션)

```bash
# 해상도 우선, 같으면 코덱 품질 순
yt-dlp -S "res,codec" URL

# AV1 코덱 선호
yt-dlp -S "+codec:av01" URL

# 파일 크기 작은 것 우선
yt-dlp -S "+size" URL
```

## 출력 파일 설정

### 파일명 템플릿

```bash
# 기본 (제목.확장자)
yt-dlp URL

# 제목 + 해상도
yt-dlp -o "%(title)s_%(height)sp.%(ext)s" URL
# → "영상제목_1080p.mp4"

# 업로드 날짜 + 제목
yt-dlp -o "%(upload_date)s_%(title)s.%(ext)s" URL
# → "20240315_영상제목.webm"

# 저장 폴더 지정
yt-dlp -o "~/Downloads/youtube/%(title)s.%(ext)s" URL
```

주요 템플릿 변수:

| 변수 | 설명 |
|------|------|
| `%(title)s` | 영상 제목 |
| `%(id)s` | 영상 ID |
| `%(ext)s` | 확장자 |
| `%(height)s` | 세로 해상도 (1080, 2160 등) |
| `%(upload_date)s` | 업로드 날짜 (YYYYMMDD) |
| `%(channel)s` | 채널명 |
| `%(playlist_index)s` | 재생목록 내 순번 |

### 출력 포맷 변환

```bash
# MP4로 변환 (merge 후 컨테이너 변환)
yt-dlp -f bestvideo+bestaudio --merge-output-format mp4 URL

# MKV로 변환
yt-dlp -f bestvideo+bestaudio --merge-output-format mkv URL
```

## 재생목록 / 채널 다운로드

```bash
# 재생목록 전체
yt-dlp PLAYLIST_URL

# 재생목록에서 특정 범위만 (3번~7번)
yt-dlp --playlist-start 3 --playlist-end 7 PLAYLIST_URL

# 재생목록 파일명에 순번 넣기
yt-dlp -o "%(playlist_index)03d_%(title)s.%(ext)s" PLAYLIST_URL
# → "001_첫번째영상.mp4", "002_두번째영상.mp4"

# 채널 전체 다운로드
yt-dlp CHANNEL_URL

# 재생목록 무시 (단일 영상만)
yt-dlp --no-playlist URL
```

### ⚠️ 하나만 받으려는데 재생목록이 전부 받아지는 경우

YouTube에서 재생목록 안의 영상을 클릭하면, URL에 `&list=`가 자동으로 붙음.
이 상태로 복사하면 본인도 모르게 재생목록 URL이 됨.

```
# 이렇게 생긴 URL은 재생목록 전체를 받음 (list= 가 붙어있음)
https://www.youtube.com/watch?v=abc123&list=PLxxxxxxxx

# 이게 진짜 단일 영상 URL
https://www.youtube.com/watch?v=abc123
```

**해결법:**

```bash
# --no-playlist 옵션이면 list=가 있어도 해당 영상 하나만 받음 ⭐
yt-dlp --no-playlist -f bestvideo+bestaudio URL

# 또는 URL에서 &list= 이후를 직접 지우기
# ?v=abc123 까지만 남기면 됨
```

항상 하나만 받고 싶으면 `.bat`에 `--no-playlist`를 기본으로 넣어두면 편함.

## 자막 다운로드

```bash
# 자막 목록 확인
yt-dlp --list-subs URL

# 한국어 자막 포함 다운로드
yt-dlp --write-sub --sub-lang ko URL

# 자동생성 자막 포함
yt-dlp --write-auto-sub --sub-lang ko URL

# 자막만 다운 (영상 없이)
yt-dlp --write-sub --sub-lang ko --skip-download URL

# 자막을 SRT 포맷으로
yt-dlp --write-sub --sub-lang ko --convert-subs srt URL
```

## 프록시 / 네트워크 설정

```bash
# 프록시 사용
yt-dlp --proxy "http://프록시주소:포트" URL

# 프록시 + 인증서 검증 무시 (사내망 등)
yt-dlp --proxy "http://프록시주소:포트" --no-check-certificates URL

# 속도 제한 (다른 작업에 영향 안 주게)
yt-dlp --limit-rate 5M URL                # 5MB/s 제한

# 재시도 횟수
yt-dlp --retries 10 URL
```

## 메타데이터 / 썸네일

```bash
# 썸네일 다운로드
yt-dlp --write-thumbnail URL

# 썸네일만 (영상 없이)
yt-dlp --write-thumbnail --skip-download URL

# 영상 정보만 보기 (다운로드 없이)
yt-dlp --print title URL
yt-dlp --print duration URL
yt-dlp --print "%(title)s | %(resolution)s | %(filesize_approx)s" URL

# JSON으로 전체 메타데이터
yt-dlp -j URL
yt-dlp -j URL | python -m json.tool       # 보기 좋게
```

## 기타 유용한 옵션

```bash
# 이미 받은 파일 건너뛰기 (중복 방지)
yt-dlp --download-archive downloaded.txt URL
# → downloaded.txt에 기록, 다음에 같은 URL이면 스킵

# 이어받기 (중단된 다운로드)
yt-dlp -c URL

# 쿠키 사용 (로그인 필요한 영상)
yt-dlp --cookies cookies.txt URL

# 브라우저에서 쿠키 추출
yt-dlp --cookies-from-browser chrome URL

# 조용한 모드 (진행률만)
yt-dlp -q URL

# 시뮬레이션 (실제 다운로드 없이 정보만)
yt-dlp -s URL
```

## Windows .bat 스크립트 예시

### 기본 다운로드 스크립트

```bat
@echo off
set URL="https://www.youtube.com/watch?v=XXXXXXXXXXX"
yt-dlp -f bestvideo+bestaudio %URL%
pause
```

### 프록시 + 인증서 무시 (사내망)

```bat
@echo off
set URL="https://www.youtube.com/watch?v=XXXXXXXXXXX"
yt-dlp --proxy "http://프록시주소:포트" --no-check-certificates -f bestvideo+bestaudio %URL%
pause
```

### 4K AV1 고정 + MP4 변환

```bat
@echo off
set URL="https://www.youtube.com/watch?v=XXXXXXXXXXX"
set OUTDIR=D:\Downloads\YouTube
yt-dlp -f "bestvideo[vcodec^=av01][height<=2160]+bestaudio" --merge-output-format mp4 -o "%OUTDIR%\%%(title)s.%%(ext)s" %URL%
pause
```

### 재생목록 일괄 다운로드

```bat
@echo off
set PLAYLIST="https://www.youtube.com/playlist?list=XXXXXXXXXX"
set OUTDIR=D:\Downloads\YouTube\playlist
yt-dlp -f bestvideo+bestaudio -o "%OUTDIR%\%%(playlist_index)03d_%%(title)s.%%(ext)s" %PLAYLIST%
pause
```

> 💡 `.bat` 파일에서 `%` 문자는 `%%`로 이스케이프해야 합니다.
> 템플릿의 `%(title)s`는 `.bat` 안에서 `%%(title)s`로 씁니다.
