# yt-dlp 명령어 레퍼런스

유튜브 및 기타 동영상 사이트에서 영상을 다운로드하는 CLI 도구.

## 설치

```bash
# pip
pip install yt-dlp

# Linux
sudo apt install yt-dlp

# Windows (winget)
winget install yt-dlp

# 업데이트
yt-dlp -U
```

---

## 기본 다운로드

```bash
# 최고 화질 영상 + 최고 음질 오디오 합쳐서 다운로드 (가장 많이 씀) ⭐
yt-dlp -f bestvideo+bestaudio URL

# 기본 (알아서 적당한 화질로)
yt-dlp URL

# 최고 화질 단일 파일 (영상+오디오 합쳐진 것 중에서)
yt-dlp -f best URL
```

> ⚠️ `bestvideo+bestaudio`는 영상과 오디오를 따로 받아서 합치므로 **ffmpeg가 설치되어 있어야** 합니다.
> `best`는 합쳐진 파일 중 최고 화질이라 ffmpeg 없이도 되지만, 화질이 떨어질 수 있음.

## 포맷 확인 및 선택

### 사용 가능한 포맷 목록 보기

```bash
yt-dlp -F URL
```

출력 예시:
```
ID   EXT  RESOLUTION  FPS  │  FILESIZE    VCODEC        ACODEC
─────────────────────────────────────────────────────────────────
140  m4a  audio only       │  3.5MiB      audio only    mp4a.40.2
251  webm audio only       │  4.2MiB      audio only    opus
136  mp4  1280x720    30   │  12MiB       avc1.4d401f   video only
247  webm 1280x720   30    │  10MiB       vp9           video only
401  mp4  2560x1440  30    │  85MiB       av01.0.12M.08 video only
571  mp4  audio only       │  8MiB        audio only    mp4a.40.2
```

### 특정 포맷 번호로 다운로드

```bash
# 포맷 ID 하나만
yt-dlp -f 401 URL

# 영상 + 오디오 조합 (+ 로 연결)
yt-dlp -f 401+571 URL

# 특정 코덱 선호
yt-dlp -f "bestvideo[vcodec^=av01]+bestaudio" URL       # AV1 영상
yt-dlp -f "bestvideo[vcodec^=avc1]+bestaudio" URL       # H.264 영상
```

### 해상도 지정

```bash
# 1080p 이하 최고 화질
yt-dlp -f "bestvideo[height<=1080]+bestaudio" URL

# 정확히 4K (2160p)
yt-dlp -f "bestvideo[height=2160]+bestaudio" URL

# 720p 이하 (모바일/데이터 절약)
yt-dlp -f "bestvideo[height<=720]+bestaudio" URL
```

## 출력 파일 설정

### 파일명 템플릿

```bash
# 기본 파일명 (제목.확장자)
yt-dlp URL

# 제목 + 해상도
yt-dlp -o "%(title)s_%(height)sp.%(ext)s" URL
# → "영상제목_1080p.mp4"

# 업로드 날짜 + 제목
yt-dlp -o "%(upload_date)s_%(title)s.%(ext)s" URL
# → "20240315_영상제목.webm"

# 저장 폴더 지정
yt-dlp -o "~/Downloads/youtube/%(title)s.%(ext)s" URL
```

주요 템플릿 변수:

| 변수 | 설명 |
|------|------|
| `%(title)s` | 영상 제목 |
| `%(id)s` | 영상 ID |
| `%(ext)s` | 확장자 |
| `%(height)s` | 세로 해상도 (1080, 2160 등) |
| `%(upload_date)s` | 업로드 날짜 (YYYYMMDD) |
| `%(channel)s` | 채널명 |
| `%(playlist_index)s` | 재생목록 내 순번 |

### 출력 포맷 변환

```bash
# MP4로 변환 (merge 후 컨테이너 변환)
yt-dlp -f bestvideo+bestaudio --merge-output-format mp4 URL

# MKV로 변환
yt-dlp -f bestvideo+bestaudio --merge-output-format mkv URL
```

## 재생목록 / 채널 다운로드

```bash
# 재생목록 전체
yt-dlp PLAYLIST_URL

# 재생목록에서 특정 범위만 (3번~7번)
yt-dlp --playlist-start 3 --playlist-end 7 PLAYLIST_URL

# 재생목록 파일명에 순번 넣기
yt-dlp -o "%(playlist_index)03d_%(title)s.%(ext)s" PLAYLIST_URL
# → "001_첫번째영상.mp4", "002_두번째영상.mp4"

# 채널 전체 다운로드
yt-dlp CHANNEL_URL

# 재생목록 무시 (단일 영상만)
yt-dlp --no-playlist URL
```

## 자막 다운로드

```bash
# 자막 목록 확인
yt-dlp --list-subs URL

# 한국어 자막 포함 다운로드
yt-dlp --write-sub --sub-lang ko URL

# 자동생성 자막 포함
yt-dlp --write-auto-sub --sub-lang ko URL

# 자막만 다운 (영상 없이)
yt-dlp --write-sub --sub-lang ko --skip-download URL

# 자막을 SRT 포맷으로
yt-dlp --write-sub --sub-lang ko --convert-subs srt URL
```

## 프록시 / 네트워크 설정

```bash
# 프록시 사용
yt-dlp --proxy "http://프록시주소:포트" URL

# 프록시 + 인증서 검증 무시 (사내망 등)
yt-dlp --proxy "http://프록시주소:포트" --no-check-certificates URL

# 속도 제한 (다른 작업에 영향 안 주게)
yt-dlp --limit-rate 5M URL                # 5MB/s 제한

# 재시도 횟수
yt-dlp --retries 10 URL
```

## 메타데이터 / 썸네일

```bash
# 썸네일 다운로드
yt-dlp --write-thumbnail URL

# 썸네일만 (영상 없이)
yt-dlp --write-thumbnail --skip-download URL

# 영상 정보만 보기 (다운로드 없이)
yt-dlp --print title URL
yt-dlp --print duration URL
yt-dlp --print "%(title)s | %(resolution)s | %(filesize_approx)s" URL

# JSON으로 전체 메타데이터
yt-dlp -j URL
yt-dlp -j URL | python -m json.tool       # 보기 좋게
```

## 기타 유용한 옵션

```bash
# 이미 받은 파일 건너뛰기 (중복 방지)
yt-dlp --download-archive downloaded.txt URL
# → downloaded.txt에 기록, 다음에 같은 URL이면 스킵

# 이어받기 (중단된 다운로드)
yt-dlp -c URL

# 쿠키 사용 (로그인 필요한 영상)
yt-dlp --cookies cookies.txt URL

# 브라우저에서 쿠키 추출
yt-dlp --cookies-from-browser chrome URL

# 조용한 모드 (진행률만)
yt-dlp -q URL

# 시뮬레이션 (실제 다운로드 없이 정보만)
yt-dlp -s URL
```

## Windows .bat 스크립트 예시

### 기본 다운로드 스크립트

```bat
@echo off
set URL="https://www.youtube.com/watch?v=XXXXXXXXXXX"
yt-dlp -f bestvideo+bestaudio %URL%
pause
```

### 프록시 + 인증서 무시 (사내망)

```bat
@echo off
set URL="https://www.youtube.com/watch?v=XXXXXXXXXXX"
yt-dlp --proxy "http://프록시주소:포트" --no-check-certificates -f bestvideo+bestaudio %URL%
pause
```

### 4K 고정 + MP4 변환

```bat
@echo off
set URL="https://www.youtube.com/watch?v=XXXXXXXXXXX"
set OUTDIR=D:\Downloads\YouTube
yt-dlp -f "bestvideo[height<=2160]+bestaudio" --merge-output-format mp4 -o "%OUTDIR%\%%(title)s.%%(ext)s" %URL%
pause
```

### 재생목록 일괄 다운로드

```bat
@echo off
set PLAYLIST="https://www.youtube.com/playlist?list=XXXXXXXXXX"
set OUTDIR=D:\Downloads\YouTube\playlist
yt-dlp -f bestvideo+bestaudio -o "%OUTDIR%\%%(playlist_index)03d_%%(title)s.%%(ext)s" %PLAYLIST%
pause
```

> 💡 `.bat` 파일에서 `%` 문자는 `%%`로 이스케이프해야 합니다.
> 템플릿의 `%(title)s`는 `.bat` 안에서 `%%(title)s`로 씁니다.
