# 캐시 / 디스크 관리

홈 디스크(`/home`)가 꽉 찰 때, 캐시 위치를 다른 디스크로 옮기는 방법.

## 용량 현황 파악 먼저

```bash
# 디스크별 사용량
df -h

# ~/.cache 안에서 뭐가 큰지
du -sh ~/.cache/*
du -sh ~/.cache/* 2>/dev/null | sort -h    # 크기순 정렬

# 주요 캐시 용량 의심 지점
du -sh ~/.cache/torch                 # PyTorch 모델, JIT 빌드
du -sh ~/.cache/torch_extensions      # JIT 컴파일 결과
du -sh ~/.cache/huggingface           # HF 모델/데이터셋
du -sh ~/.cache/pip                   # pip 캐시
du -sh ~/miniconda3/pkgs              # conda 패키지 캐시
```

## 방법 1: XDG 표준으로 통째로 옮기기

```bash
# ~/.bashrc에 추가
export XDG_CACHE_HOME=/data/cache
```

- `pip` (최신 버전), `huggingface_hub`, `poetry` 등이 이걸 따름
- 단점: 모든 프로그램이 이 표준을 따르지는 않음

## 방법 2: 프로그램별 개별 경로 (확실)

용량 큰 주범들은 자체 환경변수를 따로 가짐. 이게 가장 확실.

```bash
# ~/.bashrc에 추가

# PyTorch (모델, JIT 캐시) — 제일 큰 경우 많음
export TORCH_HOME=/data/cache/torch

# HuggingFace (모델, 데이터셋) — 수십 GB 가기 쉬움
export HF_HOME=/data/cache/huggingface

# pip 캐시
export PIP_CACHE_DIR=/data/cache/pip

# conda 패키지 캐시
export CONDA_PKGS_DIRS=/data/cache/conda-pkgs

# CUDA 컴파일 캐시
export CUDA_CACHE_PATH=/data/cache/cuda

# Triton JIT (PyTorch 2.x 컴파일)
export TRITON_CACHE_DIR=/data/cache/triton
```

적용:
```bash
source ~/.bashrc
```

## 방법 3: 심볼릭 링크 (가장 간단) ⭐

`~/.cache` 폴더 자체를 다른 디스크로 링크하면, 모든 프로그램이 자동으로 새 위치에 쓰게 됨.

```bash
# 1. 새 위치에 폴더 만들기
mkdir -p /data/cache

# 2. 기존 캐시 이동
mv ~/.cache/* /data/cache/ 2>/dev/null
mv ~/.cache/.??* /data/cache/ 2>/dev/null   # 숨김파일도

# 3. 기존 ~/.cache 제거 후 심볼릭 링크 생성
rmdir ~/.cache
ln -s /data/cache ~/.cache

# 4. 확인
ls -la ~ | grep cache
# → .cache -> /data/cache
```

> ⚠️ `/data`가 **같은 머신의 물리 디스크**일 때만. 네트워크 드라이브(NFS 등)면 속도 저하가 심함.

## 기존 캐시 이동 (일부만)

이미 쌓인 캐시를 옮기려면:

```bash
mkdir -p /data/cache

# 큰 것부터 이동
mv ~/.cache/torch /data/cache/torch
mv ~/.cache/huggingface /data/cache/huggingface
mv ~/.cache/torch_extensions /data/cache/torch_extensions

# 환경변수로 새 위치 지정 (~/.bashrc에)
export TORCH_HOME=/data/cache/torch
export HF_HOME=/data/cache/huggingface
# torch_extensions는 TORCH_EXTENSIONS_DIR로 지정
export TORCH_EXTENSIONS_DIR=/data/cache/torch_extensions
```

## 검증

```bash
# 환경변수 확인
echo $TORCH_HOME
echo $HF_HOME
echo $XDG_CACHE_HOME

# 실제 저장 경로 확인
python -c "import torch; print(torch.hub.get_dir())"
# → /data/cache/torch/hub

# 용량 비교
df -h ~          # 홈 디스크 여유 확인
df -h /data      # 데이터 디스크
```

## 캐시 정리 명령어

환경변수 설정 없이 당장 용량 확보하고 싶을 때:

```bash
# pip 캐시 비우기
pip cache purge

# conda 캐시 정리 (패키지 tarball, 사용 안 하는 패키지 등)
conda clean --all

# PyTorch JIT 컴파일 캐시
rm -rf ~/.cache/torch_extensions/

# HuggingFace 캐시 정리 (선택적)
pip install huggingface_hub[cli]
huggingface-cli delete-cache          # 대화형으로 선택 삭제
```

## 주의사항

- `sudo`로 움직이지 말 것 (소유권 꼬임)
- 실행 중인 프로세스가 쓰고 있는 캐시는 건드리지 말 것
- 심볼릭 링크 방식에서 `/data` 디스크를 언마운트하면 `~/.cache`가 깨짐 → 영구 마운트 확인
