# 조건 · 반복

`if [ ... ]`, `for`, `while` 기본 패턴. 스크립트에서 "파일 있으면 실행, 폴더 안의 파일 전부 처리" 같은 작업에 필수.

---

## 1. 조건문 `if`

### 기본 구조

```bash
if [ 조건 ]; then
    # 참일 때
elif [ 다른_조건 ]; then
    # 다른 참
else
    # 거짓
fi
```

**세미콜론 `;`** 또는 **줄바꿈** 필수. `[` 양옆에 공백도 필수 (`[`는 명령어임).

### 파일/디렉토리 존재 확인 — 가장 자주 씀

| 테스트 | 의미 |
|:---:|---|
| `-e path` | 존재 (파일이든 폴더든) |
| `-f path` | 일반 파일 존재 |
| `-d path` | 디렉토리 존재 |
| `-s path` | 파일 존재하고 크기 > 0 |
| `-r path` | 읽기 권한 |
| `-w path` | 쓰기 권한 |
| `-x path` | 실행 권한 |

```bash
if [ -f "model.pt" ]; then
    echo "found"
else
    echo "not found"
fi

# 자주 쓰는 패턴: 없으면 다운로드
if [ ! -f "model.pt" ]; then
    wget https://example.com/model.pt
fi

# 폴더 없으면 만들기
[ -d "./outputs" ] || mkdir -p "./outputs"

# 한 줄 short-circuit (아래 §5 참고)
[ -f "env.sh" ] && source env.sh
```

### 문자열 비교

```bash
if [ "$a" = "$b" ]; then ...          # 같음 (공백 포함 비교: 큰따옴표 필수)
if [ "$a" != "$b" ]; then ...         # 다름
if [ -z "$s" ]; then ...              # 비어있음 (zero length)
if [ -n "$s" ]; then ...              # 비어있지 않음
```

### 숫자 비교

| 연산자 | 의미 |
|:---:|---|
| `-eq` | equal |
| `-ne` | not equal |
| `-lt` | less than |
| `-le` | less than or equal |
| `-gt` | greater than |
| `-ge` | greater than or equal |

```bash
n=10
if [ "$n" -gt 5 ]; then echo "큼"; fi
if [ "$n" -eq 10 ]; then echo "10"; fi

# ⚠️ 숫자 비교에 = 쓰면 문자열 비교됨. 10 vs 10.0 다르게 봄
```

### AND / OR

```bash
# 안전: [ ... ] && [ ... ]
if [ -f "a.txt" ] && [ -f "b.txt" ]; then
    echo "둘 다 있음"
fi

if [ -f "a.txt" ] || [ -f "b.txt" ]; then
    echo "하나라도 있음"
fi

# [[ ]] 쓰면 더 간결 (bash 전용, posix 아님)
if [[ -f "a.txt" && -f "b.txt" ]]; then ...
if [[ "$s" == "hello"* ]]; then ...   # 와일드카드 지원
```

### `[ ]` vs `[[ ]]` 차이

- `[ ]`: POSIX 표준. 이식성 높음 (다른 쉘에서도 작동). 단, 변수 따옴표 필수.
- `[[ ]]`: bash 확장. 와일드카드/정규식 지원, 따옴표 없어도 단어 분리 안 됨.

```bash
# [[ ]]의 편리함
if [[ $file == *.mp4 ]]; then echo "mp4 파일"; fi           # 와일드카드
if [[ $s =~ ^[0-9]+$ ]]; then echo "숫자만"; fi              # 정규식
```

**실전 팁**: bash 스크립트에서는 `[[ ]]` 가 더 편함. `#!/bin/sh`처럼 POSIX sh 타겟이면 `[ ]` 필수.

## 2. 반복문 `for`

### 리스트 순회

```bash
for name in apple banana cherry; do
    echo "fruit: $name"
done
```

### 파일 순회 (글로빙)

```bash
# 현재 디렉토리 mp4 전부
for f in *.mp4; do
    echo "processing: $f"
done

# 여러 확장자
for f in *.jpg *.png *.webp; do
    echo "image: $f"
done

# 재귀: **/ 는 기본적으로 안 됨, `shopt -s globstar` 후
shopt -s globstar
for f in ./images/**/*.jpg; do
    echo "$f"
done
```

**주의**: 매칭되는 파일이 없으면 `for`가 패턴 문자 그대로 순회함:
```bash
for f in *.xyz; do echo "$f"; done
# 매칭 없으면 → echo "*.xyz" 출력해버림
```

방어:
```bash
shopt -s nullglob        # 매칭 없으면 빈 리스트
for f in *.xyz; do echo "$f"; done
```

또는 안에서 체크:
```bash
for f in *.xyz; do
    [ -f "$f" ] || continue     # 실제 파일일 때만
    echo "$f"
done
```

### 숫자 범위

```bash
# C-style
for ((i=0; i<10; i++)); do
    echo "i=$i"
done

# seq (외부 명령)
for i in $(seq 1 10); do echo $i; done
for i in $(seq 0 5 50); do echo $i; done      # 0, 5, 10, ..., 50

# brace expansion (bash)
for i in {1..10}; do echo $i; done
for i in {0..50..5}; do echo $i; done          # 0, 5, ..., 50
```

### 명령 결과 순회

```bash
# ls 결과 (⚠️ 공백 있으면 깨짐, 가능하면 *.mp4 글로빙 선호)
for f in $(ls *.mp4); do ...; done

# 더 안전: find + while read
find . -name "*.mp4" -print0 | while IFS= read -r -d '' f; do
    echo "$f"
done
```

## 3. 반복문 `while`

### 조건 반복

```bash
n=0
while [ $n -lt 10 ]; do
    echo "n=$n"
    n=$((n + 1))      # 산술: $(( ))
done
```

### 파일 한 줄씩 읽기

```bash
while IFS= read -r line; do
    echo "line: $line"
done < file.txt
```

- `IFS=` : 앞뒤 공백 보존
- `-r` : 백슬래시 이스케이프 안 함 (path에 `\` 있어도 안전)

**실전**: 이미지 목록이 파일로 있을 때 한 줄씩 처리.
```bash
cat image_list.txt
# /data/img1.jpg
# /data/img2.jpg

while IFS= read -r img; do
    python process.py --input "$img"
done < image_list.txt
```

### 명령 결과를 파이프로

```bash
find . -name "*.mp4" | while IFS= read -r f; do
    ffprobe "$f"
done
```

주의: 파이프 뒤 `while`은 서브쉘에서 실행 → 안에서 set한 변수는 바깥에서 안 보임.

## 4. `case` — 여러 패턴 분기

```bash
case "$1" in
    start)
        echo "start"
        ;;
    stop|halt)
        echo "stop"
        ;;
    *.mp4)
        echo "video file"
        ;;
    *)
        echo "unknown"
        ;;
esac
```

- 각 분기는 `;;`로 끝
- `|`로 패턴 OR
- `*)` = 기본값 (default)
- 패턴에 와일드카드 사용 가능

`run_3d_photo.sh`의 named-flag 파싱이 이 `case` 구조 사용.

## 5. Short-circuit `&&` 와 `||` — 한 줄 조건

```bash
# 성공하면 다음 실행
command1 && command2
# = command1이 성공(exit 0)하면 command2 실행

# 실패하면 다음 실행
command1 || command2
# = command1이 실패(exit != 0)하면 command2 실행
```

실전:

```bash
# 폴더 없으면 만들기
[ -d outputs ] || mkdir outputs

# env.sh 있으면 source
[ -f env.sh ] && source env.sh

# wget 실패하면 에러 남기고 종료
wget $URL || { echo "다운로드 실패"; exit 1; }

# 체이닝
mkdir -p build && cd build && cmake .. && make
# 하나라도 실패하면 거기서 멈춤
```

**`if` 대신 한 줄로** 간단한 조건에 편함.

## 6. `set` 옵션 — 스크립트 안전장치

스크립트 맨 위에 넣는 관용구.

```bash
#!/bin/bash
set -e      # 명령 하나라도 실패(exit != 0)하면 즉시 종료
set -u      # 정의 안 된 변수 사용하면 에러
set -o pipefail    # 파이프라인의 어느 명령이든 실패하면 실패로 간주
# 줄여서
set -euo pipefail
```

### 왜 중요한가

`set -e` 없으면:
```bash
#!/bin/bash
cd /important/dir    # 실패해도
rm -rf *              # 계속 진행 → 홈 디렉토리에서 rm -rf * 실행될 수도
```

`set -e`로:
```bash
#!/bin/bash
set -e
cd /important/dir    # 실패하면 바로 종료, rm 실행 안 됨
rm -rf *
```

**단, `set -e`에도 걸리지 않는 경우 있음**:
- `||` 뒤쪽 명령
- 조건문 안의 명령 (`if cmd; then ...`)
- 파이프라인의 중간 명령 (→ `set -o pipefail`로 보완)

## 7. 실전 패턴

### 사례 A: 폴더 안 모든 이미지를 파이프라인에 돌리기

```bash
#!/bin/bash
set -euo pipefail

INPUT_DIR="./images"
OUTPUT_DIR="./outputs"
mkdir -p "$OUTPUT_DIR"

shopt -s nullglob
for img in "$INPUT_DIR"/*.{jpg,jpeg,png}; do
    stem=$(basename "$img")
    stem="${stem%.*}"
    out="$OUTPUT_DIR/${stem}_result.mp4"

    if [ -f "$out" ]; then
        echo "[skip] $out"
        continue
    fi

    echo "[run] $img"
    python process.py --input "$img" --output "$out" || {
        echo "[fail] $img"
        continue
    }
done
```

- `set -euo pipefail`: 안전장치
- `shopt -s nullglob`: 매칭 없어도 안전
- `continue`: skip / fail 시 다음 파일로
- `[ -f "$out" ] && continue`: 이미 처리된 건 건너뜀

### 사례 B: 파라미터 스위프

```bash
#!/bin/bash
set -euo pipefail

for disp in 15 20 25 30 35; do
    for tile in 2 3; do
        echo "=== disp=$disp tile=$tile ==="
        python image_to_3d_photo.py \
            --input ./images \
            --disp $disp \
            --tile_num $tile
    done
done
```

### 사례 C: 서버 자원 기다리기

```bash
# GPU 메모리가 10GB 미만 쓰일 때까지 대기 (다른 작업 끝나기 기다리기)
while true; do
    used=$(nvidia-smi --query-gpu=memory.used --format=csv,noheader,nounits | head -1)
    if [ "$used" -lt 10000 ]; then
        echo "GPU 여유: ${used}MB 사용중, 작업 시작"
        break
    fi
    echo "$used MB 사용중, 대기..."
    sleep 60
done

python train.py
```

### 사례 D: 인자 유효성 검사

```bash
#!/bin/bash
if [ $# -lt 1 ]; then
    echo "Usage: $0 <input_folder>" >&2
    exit 1
fi

INPUT="$1"
if [ ! -d "$INPUT" ]; then
    echo "[ERROR] not a directory: $INPUT" >&2
    exit 1
fi

# 실제 작업...
```

## 8. 실수하기 쉬운 지점

### 실수 1: `[`, `]` 양옆 공백 빠뜨림

```bash
if [-f "file" ]; then ...     # ❌ [ 뒤에 공백 없음 → command not found: [-f
if [ -f "file" ]; then ...    # ✅
```

`[`는 그냥 명령어. 공백으로 인자 구분 필수.

### 실수 2: 변수를 큰따옴표 없이 `[ ]`에 넣음

```bash
s=""
if [ $s = "hello" ]; then ...   # ❌ $s가 빈 문자열이면 → if [ = "hello" ] → 문법 에러
if [ "$s" = "hello" ]; then ... # ✅
```

### 실수 3: `for f in $(ls ...)` 쓰다가 공백 파일명에 터짐

```bash
for f in $(ls); do echo "$f"; done
# "My File.mp4" 같은 공백 포함 파일명은 둘로 쪼개짐
```

해결: 글로빙 직접, 또는 find + while read.
```bash
for f in *.mp4; do echo "$f"; done          # 글로빙 (공백 OK)
find . -name "*.mp4" -print0 | while IFS= read -r -d '' f; do ...; done  # find 방식
```

### 실수 4: 숫자 비교에 `=` 씀

```bash
if [ "$n" = 10 ]; then ...    # 문자열 비교. "10"과 "10.0" 다름
if [ "$n" -eq 10 ]; then ...  # 숫자 비교. 정수만.
```

소수점 비교는 bash 기본으로는 안 됨. `awk` / `bc` / Python 사용.
```bash
if awk "BEGIN{exit !(3.14 > 3)}"; then echo "yes"; fi
```

### 실수 5: `set -e`가 안 먹히는 케이스

```bash
set -e

# || 뒤는 set -e 안 걸림
command_that_fails || echo "실패했지만 스크립트는 계속"

# 함수 안에서도 명시적 체크 필요한 경우 있음
foo() {
    false
    echo "여기 도달하면 set -e가 안 먹힌 것"
}
```

### 실수 6: `while read`에서 `IFS=` 빼먹음

```bash
while read line; do
    echo "[$line]"
done < file.txt
# 앞뒤 공백, 탭 잘림

while IFS= read -r line; do
    echo "[$line]"
done < file.txt
# 원본 그대로 보존
```

**파일 한 줄씩 읽기는 항상 `while IFS= read -r line`** 으로 외워두면 됨.

## 9. 한 줄 요약

```bash
# 파일 있으면 source
[ -f env.sh ] && source env.sh

# 없으면 만들기
[ -d outputs ] || mkdir -p outputs

# 폴더 안 파일 전부 처리
for f in ./images/*.jpg; do python process.py "$f"; done

# 파이프로 넘어온 내용 한 줄씩
find . -name "*.mp4" | while IFS= read -r f; do ffprobe "$f"; done

# 파라미터 스위프
for d in 15 20 25 30; do python run.py --disp $d; done

# 스크립트 안전장치
set -euo pipefail
```
