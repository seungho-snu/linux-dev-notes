# 파일 & 폴더 복사·이동 명령어 모음

## cp — 복사

```bash
# ── 파일 복사 ──
cp file.txt backup.txt                  # 같은 폴더에 이름 바꿔 복사
cp file.txt ~/backup/                   # 다른 폴더로 복사 (이름 유지)
cp file.txt ~/backup/new_name.txt       # 다른 폴더 + 이름 변경

# ── 폴더 복사 ──
cp -r src_dir/ dst_dir/                 # 폴더 통째로 복사 (-r: recursive)
cp -r src_dir/ dst_dir/src_dir/         # dst_dir 안에 src_dir 생성됨 (dst_dir 이미 존재 시)

# ── 자주 쓰는 옵션 ──
cp -i file.txt ~/backup/               # 덮어쓰기 전 확인 (interactive)
cp -n file.txt ~/backup/               # 이미 있으면 건너뜀 (no-clobber)
cp -u file.txt ~/backup/               # 원본이 더 새로울 때만 복사 (update)
cp -v file.txt ~/backup/               # 복사 과정 출력 (verbose)
cp -a src_dir/ dst_dir/                # 권한·타임스탬프·심볼릭링크 모두 보존 (archive)

# ── 여러 파일 한번에 ──
cp file1.txt file2.txt ~/backup/       # 여러 파일을 한 폴더로
cp *.py ~/backup/                      # 와일드카드: .py 파일 전부
cp -r dir1/ dir2/ ~/backup/            # 여러 폴더를 한 폴더로
```

### cp 옵션 요약

| 옵션 | 의미 | 설명 |
|------|------|------|
| `-r` | recursive | 폴더와 하위 내용 전부 복사 |
| `-a` | archive | `-r` + 권한/소유자/타임스탬프/심볼릭링크 보존 |
| `-i` | interactive | 덮어쓰기 전 확인 |
| `-n` | no-clobber | 기존 파일 덮어쓰지 않음 |
| `-u` | update | 원본이 더 최신일 때만 복사 |
| `-v` | verbose | 복사되는 파일명 출력 |
| `-p` | preserve | 권한·타임스탬프 보존 |
| `-l` | link | 복사 대신 하드링크 생성 |
| `-s` | symbolic-link | 복사 대신 심볼릭링크 생성 |

## mv — 이동 & 이름 변경

```bash
# ── 파일 이동 ──
mv file.txt ~/project/                 # 다른 폴더로 이동
mv file.txt ~/project/new_name.txt     # 이동 + 이름 변경

# ── 이름 변경 (같은 폴더 내) ──
mv old_name.txt new_name.txt           # 파일 이름 변경
mv old_dir/ new_dir/                   # 폴더 이름 변경

# ── 폴더 이동 ──
mv src_dir/ ~/project/                 # 폴더 통째로 이동 (-r 필요 없음!)

# ── 자주 쓰는 옵션 ──
mv -i file.txt ~/project/             # 덮어쓰기 전 확인
mv -n file.txt ~/project/             # 이미 있으면 건너뜀
mv -v file.txt ~/project/             # 이동 과정 출력
mv -u file.txt ~/project/             # 원본이 더 새로울 때만 이동

# ── 여러 파일 한번에 ──
mv *.log ~/logs/                       # .log 파일 전부 이동
mv file1.txt file2.txt ~/project/     # 여러 파일을 한 폴더로
```

> 💡 **cp vs mv**: `cp`는 원본이 남고, `mv`는 원본이 사라짐 (잘라내기+붙여넣기)

## rsync — 고급 복사·동기화

```bash
# ── 기본 사용법 ──
rsync -av src_dir/ dst_dir/            # 폴더 동기화 (archive + verbose)
rsync -av src_dir dst_dir/             # ⚠️ 주의: 끝에 / 유무로 동작이 다름!

# src_dir/  → dst_dir 안에 src_dir의 '내용물'이 들어감
# src_dir   → dst_dir 안에 src_dir '폴더 자체'가 들어감

# ── 진행률 표시 ──
rsync -av --progress src/ dst/         # 파일별 진행률
rsync -av --info=progress2 src/ dst/   # 전체 진행률 (대용량에 유용)

# ── 변경된 파일만 복사 (증분 백업) ──
rsync -avu src/ dst/                   # -u: 새로운 파일만 복사
rsync -av --delete src/ dst/           # 원본에서 삭제된 파일은 대상에서도 삭제

# ── 특정 파일 제외/포함 ──
rsync -av --exclude='*.log' src/ dst/           # .log 파일 제외
rsync -av --exclude='__pycache__' src/ dst/     # 특정 폴더 제외
rsync -av --include='*.py' --exclude='*' src/ dst/  # .py만 복사

# ── 원격 서버 복사 (scp 대체) ──
rsync -av local_dir/ user@server:/remote/path/  # 로컬 → 서버
rsync -av user@server:/remote/path/ local_dir/  # 서버 → 로컬

# ── 드라이런 (실제 복사 안 함, 미리 확인) ──
rsync -avn src/ dst/                   # -n: dry-run
```

### rsync 옵션 요약

| 옵션 | 의미 | 설명 |
|------|------|------|
| `-a` | archive | 권한·타임스탬프·심볼릭링크 등 모두 보존 |
| `-v` | verbose | 처리 과정 출력 |
| `-u` | update | 대상이 더 최신이면 건너뜀 |
| `-n` | dry-run | 실제 실행 안 하고 시뮬레이션 |
| `-z` | compress | 전송 시 압축 (원격 복사에 유용) |
| `--progress` | | 파일별 전송 진행률 표시 |
| `--delete` | | 원본에 없는 파일은 대상에서 삭제 |
| `--exclude` | | 특정 패턴 제외 |

## scp — 원격 서버 간 복사

```bash
# ── 로컬 → 서버 ──
scp file.txt user@server:/remote/path/
scp -r local_dir/ user@server:/remote/path/     # 폴더 복사

# ── 서버 → 로컬 ──
scp user@server:/remote/file.txt ./
scp -r user@server:/remote/dir/ ./local_dir/    # 폴더 복사

# ── 서버 → 서버 ──
scp user1@server1:/path/file.txt user2@server2:/path/

# ── 포트 지정 ──
scp -P 2222 file.txt user@server:/path/         # SSH 포트가 22가 아닐 때
```

> 💡 **scp vs rsync**: 대용량이나 반복 복사는 `rsync`가 훨씬 효율적 (변경분만 전송)

## 실전 패턴 모음

```bash
# ── 프로젝트 백업 (불필요 파일 제외) ──
rsync -av --exclude='.git' --exclude='__pycache__' \
    --exclude='*.pyc' --exclude='wandb/' \
    ~/project/ ~/backup/project/

# ── 학습 체크포인트를 서버에서 로컬로 ──
rsync -avz --progress user@gpu-server:/data/checkpoints/ ./checkpoints/

# ── 특정 확장자만 모아서 복사 ──
find . -name "*.py" -exec cp {} ~/backup/python_files/ \;
find . -name "*.pt" | xargs -I{} cp {} ~/backup/models/

# ── 디렉토리 구조만 복사 (파일 없이) ──
find src_dir/ -type d -exec mkdir -p dst_dir/{} \;
rsync -av -f"+ */" -f"- *" src_dir/ dst_dir/   # rsync 방식

# ── 심볼릭 링크로 연결 (복사 대신) ──
ln -s /data/dataset ~/project/dataset           # 원본은 /data에, 링크로 접근
ln -s /usr/local/cuda-12.4 /usr/local/cuda      # CUDA 버전 전환용

# ── 대용량 파일 복사 시 진행률 확인 ──
rsync -av --info=progress2 big_file.tar.gz ~/backup/
# 또는
pv big_file.tar.gz > ~/backup/big_file.tar.gz   # pv 설치 필요
```

## 주의사항 & 팁

- **`cp -r` 끝에 `/` 주의**: `cp -r dir1/ dir2/`에서 dir2가 이미 존재하면 `dir2/dir1/`이 됨
- **`rsync` 끝에 `/` 주의**: 소스 경로 끝 `/` 유무에 따라 내용물 복사 vs 폴더째 복사 달라짐
- **권한 보존**: 백업 시 `-a` (archive) 옵션 사용 권장
- **대용량 복사**: `cp`보다 `rsync --progress` 추천 (진행률 + 중단 시 이어하기 가능)
- **원격 서버**: 단순 복사는 `scp`, 반복·대용량은 `rsync -avz`
- **위험한 명령**: `mv`는 되돌리기 없음! 중요 파일은 `cp`로 먼저 백업 후 이동
