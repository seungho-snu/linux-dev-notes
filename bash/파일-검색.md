# 파일 & 내용 검색 명령어 모음

## grep — 파일 내용 검색

```bash
# ── 기본 사용법 ──
grep "단어" file.txt                   # 파일 안에서 "단어" 포함된 줄 출력
grep "단어" *.py                       # .py 파일들에서 검색

# ── 폴더 전체 검색 (재귀) ──
grep -r "단어" 폴더/                   # 하위 폴더까지 전부 검색
grep -rl "단어" 폴더/                  # 매칭된 파일명만 출력
grep -rn "단어" 폴더/                  # 줄 번호도 표시

# ── 자주 쓰는 옵션 ──
grep -i "word" 폴더/                   # 대소문자 무시 (case-insensitive)
grep -w "model" 폴더/                  # 정확한 단어 매칭 (model_v2 안 걸림)
grep -c "단어" file.txt                # 매칭 줄 수만 출력
grep -v "제외할단어" file.txt          # 매칭 안 되는 줄만 출력 (반전)

# ── 특정 확장자만 검색 ──
grep -r "import torch" --include="*.py" 폴더/
grep -r "단어" --include="*.{py,sh}" 폴더/     # 여러 확장자
grep -r "단어" --exclude="*.log" 폴더/         # 특정 확장자 제외
grep -r "단어" --exclude-dir='.git' 폴더/      # 특정 폴더 제외

# ── 전후 줄도 같이 보기 ──
grep -A 3 "error" log.txt              # 매칭 줄 + 아래 3줄 (After)
grep -B 2 "error" log.txt              # 매칭 줄 + 위 2줄 (Before)
grep -C 2 "error" log.txt              # 매칭 줄 + 위아래 2줄 (Context)
```

### grep 옵션 요약

| 옵션 | 의미 | 설명 |
|------|------|------|
| `-r` | recursive | 하위 폴더까지 검색 |
| `-l` | files-with-matches | 파일명만 출력 |
| `-n` | line-number | 줄 번호 표시 |
| `-i` | ignore-case | 대소문자 무시 |
| `-w` | word-regexp | 정확한 단어 매칭 |
| `-v` | invert-match | 매칭 안 되는 줄 출력 |
| `-c` | count | 매칭 줄 수만 출력 |
| `-A N` | after | 매칭 줄 + 아래 N줄 |
| `-B N` | before | 매칭 줄 + 위 N줄 |
| `-C N` | context | 매칭 줄 + 위아래 N줄 |

## find — 파일명 검색

```bash
# ── 이름으로 찾기 ──
find 폴더/ -name "*.py"                # .py 파일 전부
find 폴더/ -name "*3376*"              # 파일명에 3376 포함
find 폴더/ -iname "*.JPG"             # 대소문자 무시 (jpg, JPG, Jpg 다 매칭)

# ── 타입 지정 ──
find 폴더/ -type f -name "*.pt"        # 파일만 (-type f)
find 폴더/ -type d -name "output*"     # 폴더만 (-type d)

# ── 크기로 찾기 ──
find 폴더/ -size +100M                 # 100MB 초과 파일
find 폴더/ -size +1G                   # 1GB 초과 파일
find 폴더/ -size -10k                  # 10KB 미만 파일

# ── 시간으로 찾기 ──
find 폴더/ -mtime -1                   # 최근 24시간 내 수정된 파일
find 폴더/ -mtime +7                   # 7일 넘게 안 건드린 파일
find 폴더/ -newer reference.txt        # reference.txt보다 최근에 수정된 파일

# ── 찾은 결과로 작업하기 ──
find 폴더/ -name "*.log" -delete                        # 찾아서 삭제
find 폴더/ -name "*.py" -exec grep -l "torch" {} \;     # 찾은 파일에서 grep
find 폴더/ -name "*.bak" -exec rm {} \;                 # 찾아서 삭제 (exec)
find 폴더/ -name "*.py" | xargs wc -l                   # 찾은 .py 파일 줄 수 합계
```

## 실전 패턴

```bash
# ── 프로젝트에서 특정 함수 사용처 찾기 ──
grep -rn "def train_step" --include="*.py" ~/project/

# ── .git, __pycache__ 제외하고 검색 ──
grep -rn "CUDA" --include="*.py" --exclude-dir={.git,__pycache__} ~/project/

# ── 대용량 체크포인트 파일 찾기 ──
find ~/project/ -name "*.pt" -size +500M

# ── 빈 폴더 찾아서 정리 ──
find ~/project/ -type d -empty

# ── 최근 수정한 Python 파일 확인 ──
find ~/project/ -name "*.py" -mtime -1 -type f
```

> 💡 **grep vs find**: `grep`은 파일 **내용** 검색, `find`는 **파일명/속성** 검색. 조합하면 강력!
