# 문자열 처리

파일명 가공, 로그 파싱, 경로 조작 등에서 자주 쓰는 bash 문자열 조작 문법과 `sed`/`awk`/`grep` 기초.

---

## 1. 변수 내용 조작 — 파라미터 확장 (`${...}`)

bash 내장 기능. 외부 명령 없이 문자열을 자를/바꿀 수 있음.

### 길이 / 기본값

```bash
s="hello world"

echo ${#s}              # 문자열 길이: 11
echo "${empty:-default}" # 비어있으면 기본값: default
echo "${VAR:=xyz}"       # 비어있으면 xyz 대입 (동시에 변수 set)
```

### 앞/뒤 제거 (prefix/suffix strip)

| 문법 | 의미 | 예시 (`f=image.tar.gz`) |
|:---:|---|---|
| `${var#pat}` | **앞**에서 패턴 최소 매칭 제거 | `${f#*.}` → `tar.gz` |
| `${var##pat}` | **앞**에서 패턴 최대 매칭 제거 | `${f##*.}` → `gz` |
| `${var%pat}` | **뒤**에서 패턴 최소 매칭 제거 | `${f%.*}` → `image.tar` |
| `${var%%pat}` | **뒤**에서 패턴 최대 매칭 제거 | `${f%%.*}` → `image` |

**암기 팁**: `#`은 키보드에서 `$` 앞에 있음 → **앞** 제거. `%`는 뒤에 있음 → **뒤** 제거. 기호 한 개는 최소(greedy 아님), 두 개는 최대.

```bash
path="/home/seungho/project/my_file.tar.gz"

echo "${path##*/}"      # 파일명만: my_file.tar.gz
echo "${path%/*}"       # 폴더 경로만: /home/seungho/project
echo "${path%.*}"       # 확장자 제거: /home/.../my_file.tar
echo "${path##*.}"      # 확장자만: gz
```

**경로 조작에 엄청 많이 씀.**

### 치환 (replace)

| 문법 | 의미 |
|:---:|---|
| `${var/old/new}` | **첫 번째** 매칭만 치환 |
| `${var//old/new}` | **모든** 매칭 치환 |

```bash
s="2026-04-21_session-log.txt"

echo "${s/-/_}"         # 2026_04-21_session-log.txt (첫 하이픈만)
echo "${s//-/_}"         # 2026_04_21_session_log.txt (전부)
echo "${s%.txt}.bak"     # 확장자 바꾸기: 2026-04-21_session-log.bak
```

### 대소문자

```bash
s="Hello World"
echo "${s,,}"           # 전부 소문자: hello world
echo "${s^^}"           # 전부 대문자: HELLO WORLD
```

## 2. `sed` — 스트림 에디터

파일/stdin 내용을 한 줄씩 읽어 치환/삭제/추출. 패턴 매칭과 정규식 지원.

### 치환 (가장 많이 씀)

```bash
# 패턴: sed 's/old/new/' 
#       s = substitute, / 는 구분자 (/ 대신 다른 문자 가능)

echo "hello world" | sed 's/world/there/'        # hello there

# 파일에서 치환해서 출력
sed 's/foo/bar/' file.txt                        # 각 줄의 첫 foo만 → bar
sed 's/foo/bar/g' file.txt                       # g = global, 한 줄에 여러 개도 다 바꿈

# 대소문자 무시
sed 's/foo/bar/gi' file.txt                      # i = case-insensitive

# 파일 직접 수정 (in-place)
sed -i 's/foo/bar/g' file.txt                    # ⚠️ 실행 전 백업 권장
sed -i.bak 's/foo/bar/g' file.txt                # file.txt.bak 자동 백업 남김
```

### 줄 삭제

```bash
sed '5d' file.txt            # 5번째 줄 삭제
sed '/error/d' file.txt      # 'error' 포함하는 줄 전부 삭제
sed '1,10d' file.txt         # 1~10번째 줄 삭제
sed -i '/DEBUG/d' log.txt    # 파일에서 DEBUG 줄 영구 삭제
```

### 특정 줄만 출력

```bash
sed -n '5p' file.txt         # 5번째 줄만 출력 (-n 없으면 전체 + 5줄 추가)
sed -n '10,20p' file.txt     # 10~20번째 줄만
sed -n '/ERROR/p' file.txt   # ERROR 포함 줄만 (= grep 과 유사)
```

### 구분자 `/` 대신 다른 문자

경로 치환할 때 `/`가 많아서 이스케이프 귀찮으면:

```bash
# /home/old → /home/new 치환. 슬래시 이스케이프
sed 's/\/home\/old/\/home\/new/g' file.txt     # 💀 읽기 힘듦

# | 나 # 로 구분자 바꾸기 (훨씬 깔끔)
sed 's|/home/old|/home/new|g' file.txt
sed 's#/home/old#/home/new#g' file.txt
```

## 3. `awk` — 컬럼 기반 처리

공백/탭으로 구분된 데이터에서 **N번째 필드**를 꺼낼 때 압도적으로 편함.

```bash
# 기본: 공백 구분, $1 = 첫 번째 필드, $2 = 두 번째, ...
echo "foo bar baz" | awk '{print $2}'          # bar
echo "foo bar baz" | awk '{print $3, $1}'      # baz foo

# ls 결과에서 파일명만 추출 (9번째 컬럼)
ls -la | awk '{print $9}'

# ps 결과에서 PID(2)와 COMMAND(11~)만
ps aux | awk '{print $2, $11}'

# nvidia-smi 결과에서 GPU 메모리 사용량
nvidia-smi --query-gpu=memory.used --format=csv,noheader

# CSV 파일의 2번째 컬럼 (구분자 지정: -F)
awk -F',' '{print $2}' data.csv

# 조건부: 3번째 컬럼이 100 이상인 줄만
awk '$3 >= 100' data.txt

# 합계 계산 — 2번째 컬럼 합
awk '{sum += $2} END {print sum}' data.txt
```

`awk`가 복잡해지면 그건 Python 쓸 신호. 단순 컬럼 추출만 가볍게.

## 4. `grep` — 패턴 검색

```bash
grep "pattern" file.txt              # 패턴 포함 줄
grep -i "pattern" file.txt           # 대소문자 무시
grep -v "pattern" file.txt           # 패턴 없는 줄만 (inverse)
grep -n "pattern" file.txt           # 줄 번호 포함
grep -c "pattern" file.txt           # 매칭된 줄 수만 카운트
grep -l "pattern" *.py               # 매칭된 파일명만 (list)
grep -r "pattern" ./                 # 하위 폴더까지 재귀 검색
grep -E "foo|bar" file.txt           # 확장 정규식 (egrep와 동일)

# 자주 쓰는 조합
ps aux | grep python | grep -v grep  # python 프로세스 (grep 자기 자신 제외)
nvidia-smi | grep MiB                # 메모리 사용량 줄만
grep -rn "TODO" ./src/               # 소스에서 TODO 전부 찾기
```

## 5. 실전 패턴

### 파일 일괄 이름 변경

```bash
# .JPG → .jpg
for f in *.JPG; do
    mv "$f" "${f%.JPG}.jpg"
done

# prefix 붙이기: old_*.mp4 → new_*.mp4
for f in old_*.mp4; do
    mv "$f" "new_${f#old_}"
done

# suffix 기반 이동: _backup 붙은 파일들을 backup/ 폴더로
mkdir -p backup
for f in *_backup.*; do
    mv "$f" backup/
done
```

### 경로에서 파일명/폴더/확장자 분리

```bash
p="/home/seungho/DB/test/images_4k/0020.jpg"

dir="${p%/*}"           # /home/seungho/DB/test/images_4k
file="${p##*/}"         # 0020.jpg
stem="${file%.*}"       # 0020
ext="${file##*.}"       # jpg

echo "dir=$dir file=$file stem=$stem ext=$ext"
```

### 로그에서 에러만 뽑기

```bash
# 마지막 실행 로그에서 ERROR/WARNING 추출
tail -100 session.log | grep -E "ERROR|WARNING"

# 특정 시간대 (2026-04-21 14:* 로 시작하는 줄)
grep "^2026-04-21 14:" session.log

# nvidia-smi에서 내 GPU만 (이름에 A100 포함)
nvidia-smi | grep A100
```

### GPU 메모리 사용량 파싱

```bash
# "8192 MiB / 40960 MiB" 같은 문자열에서 사용량만
nvidia-smi --query-gpu=memory.used --format=csv,noheader,nounits
# → 8192

# bash 내장으로 가공
mem=$(nvidia-smi --query-gpu=memory.used --format=csv,noheader,nounits | head -1)
echo "current GPU mem: ${mem} MiB"
```

### CSV 특정 컬럼 추출

```bash
# id,name,score 에서 name만
awk -F',' '{print $2}' data.csv

# 헤더 제외하고 2번째 컬럼
awk -F',' 'NR>1 {print $2}' data.csv
```

## 6. 실수하기 쉬운 지점

### 실수 1: `sed -i` 확실히 백업 없이 씀

```bash
sed -i 's/old/new/g' critical_config.yml
# 패턴 잘못 썼으면 파일 망가짐, 복구 불가
```

**방어**: 항상 `.bak` 옵션 사용하거나, 먼저 `-i` 없이 출력 확인.
```bash
sed 's/old/new/g' critical_config.yml | head      # 결과 먼저 확인
sed -i.bak 's/old/new/g' critical_config.yml     # 백업 남기며 수정
```

### 실수 2: `${var/old/new}` 에서 old가 특수문자 포함

```bash
path="/home/user/file"
echo "${path/\//_}"       # 슬래시 하나를 _ 로 치환
# → _home/user/file
```

첫 슬래시만 치환. 전체 하려면 `//`.

### 실수 3: `$()` 와 백틱의 혼용

```bash
# 둘 다 "명령 결과를 변수에"
now=$(date)
now=`date`              # 옛날 문법, nesting 안 됨

# 권장: $() — 중첩 가능하고 가독성 좋음
files=$(ls $(pwd))
```

### 실수 4: 공백 있는 문자열을 따옴표 없이

```bash
s="hello world"
echo $s                 # hello world (공백 보존 되긴 하지만 단어 분리 발생)
for x in $s; do echo "--$x--"; done
# → --hello--
# → --world--       # 단어 분리됨

echo "$s"               # 항상 큰따옴표로 감싸는 게 안전
for x in "$s"; do echo "--$x--"; done
# → --hello world-- (한 덩어리)
```

**규칙**: 변수 확장 시 `"$var"` 큰따옴표로 감싸기. 특히 파일명, 경로에 공백 있을 수 있으니 습관 필수.

### 실수 5: `awk`에서 `$` 가 bash로 해석됨

```bash
ls | awk '{print $1}'         # ✅ 작은따옴표 — awk가 $1 해석
ls | awk "{print $1}"         # ❌ 큰따옴표 — bash가 먼저 $1 치환해버림
```

`awk`/`sed` 스크립트는 항상 **작은따옴표**로.

## 7. 한 줄 요약 치트시트

```bash
# 변수 내용 조작
${var#pat}    ${var##pat}     # 앞에서 최소/최대 제거
${var%pat}    ${var%%pat}     # 뒤에서 최소/최대 제거
${var/a/b}    ${var//a/b}     # 첫/모든 치환
${#var}                        # 길이

# 파이프 조합 3대장
grep "pat" file | awk '{print $2}'       # 패턴 매칭 후 컬럼 추출
cat file | sed 's/a/b/g' > new_file      # 치환해서 새 파일
ls | grep -v backup | awk '{print}'      # 필터링

# 파일 in-place 수정 (백업 필수)
sed -i.bak 's/old/new/g' file.txt
```
