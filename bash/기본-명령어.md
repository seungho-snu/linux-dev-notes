# Bash 기본 명령어 & 환경 설정

## 디렉토리 / 파일

```bash
# 현재 위치 확인
pwd

# 디렉토리 이동
cd ~/project          # 홈 아래 project 폴더로
cd ..                 # 상위 폴더로
cd -                  # 이전 폴더로 돌아가기

# 목록 보기
ls                    # 기본 목록
ls -la                # 숨김파일 포함, 상세 정보
ls -lh                # 파일 크기 읽기 쉽게 (KB, MB)
ls /usr/local/cuda*   # 와일드카드로 패턴 매칭

# 폴더 생성
mkdir mydir           # 단일 폴더
mkdir -p a/b/c        # 중간 경로까지 한번에 생성

# 삭제
rm file.txt           # 파일 삭제
rm -r mydir/          # 폴더 통째로 삭제
rm -rf ~/.cache/torch_extensions/   # 강제 삭제 (확인 없이)
```

## 환경변수 (export)

```bash
# 현재 세션에만 적용 (터미널 닫으면 사라짐)
export PATH=/usr/local/cuda-12.4/bin:$PATH
export LD_LIBRARY_PATH=/usr/local/cuda-12.4/lib64:$LD_LIBRARY_PATH

# 현재 설정된 값 확인
echo $PATH
echo $LD_LIBRARY_PATH
echo $CUDA_VISIBLE_DEVICES

# 환경변수 해제
unset CUDA_VISIBLE_DEVICES
```

## ~/.bashrc (영구 설정)

```bash
# .bashrc = 터미널 열 때마다 자동 실행되는 스크립트
# ⚠️ 여기에 추가하면 '모든' bash 세션에 항상 적용됨

# 편집
nano ~/.bashrc        # nano 에디터로 열기
code ~/.bashrc        # VS Code로 열기 (WSL 연동 시)

# 수정 후 즉시 반영
source ~/.bashrc

# 맨 아래에 추가하는 단축 방법
echo 'export MY_VAR=hello' >> ~/.bashrc
```

> 💡 **팁**: 특정 conda 환경에서만 환경변수를 적용하고 싶으면 → [conda/환경별-설정.md](../conda/환경별-설정.md) 참고
> 여러 줄을 한번에 추가하고 싶거나 `>>`/`>`/`<<EOF` 같은 리다이렉트 문법이 헷갈리면 → [리다이렉트-heredoc.md](리다이렉트-heredoc.md) 참고

## 프로세스 / 시스템

```bash
# GPU 상태 확인
nvidia-smi

# 실시간 GPU 모니터링 (1초마다 갱신)
watch -n 1 nvidia-smi

# 디스크 용량 확인
df -h                 # 전체 디스크
du -sh ~/project/*    # 폴더별 크기

# 파일 찾기
find ~ -name "*.pt"   # 홈 디렉토리에서 .pt 파일 찾기
which nvcc            # nvcc가 어디 설치되어 있는지
```

## 파일 다운로드

```bash
# wget으로 파일 다운로드
wget https://example.com/model.pt

# 이어받기 (중간에 끊겼을 때)
wget -c https://example.com/model.pt

# 출력 파일명 지정
wget -O my_model.pt https://example.com/model.pt
```

## 유용한 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl+C` | 실행 중인 명령 중단 |
| `Ctrl+L` | 화면 클리어 (clear) |
| `Ctrl+R` | 이전 명령어 검색 |
| `Tab` | 자동완성 |
| `↑` / `↓` | 이전/다음 명령어 |
